# Awareness 2026

Project static GitHub Pages.

## Struktur
- `index.html`
- `assets/images/`
- `assets/videos/`

## Cara upload ke repository
Upload seluruh isi folder ini ke root repository `awareness2026`.
Jangan upload folder pembungkus `awareness2026` jika repository sudah ada; upload `index.html` dan folder `assets` langsung ke root repo.

Semua asset menggunakan path relatif, tanpa Google Drive/CDN eksternal.
